Персональный сайт

Задание: Создать HTML-документ с корректной базовой структурой (DOCTYPE, html, head, body). Указать кодировку документа UTF-8 и заголовок страницы. Разместить на странице: основной заголовок с именем или псевдонимом автора; текстовое описание (краткую информацию о себе); список интересов или навыков; изображение (локальное или по URL); гиперссылку на внешний информационный ресурс.

Форма регистрации

Задание: На странице должна быть HTML-форма с: текстовым полем для ввода имени пользователя; числовым полем для ввода возраста; кнопкой «Проверить». При нажатии на кнопку необходимо: считать введенные данные с помощью JavaScript; проверить корректность ввода: имя не должно быть пустым; возраст должен быть числом больше 0; в зависимости от возраста вывести сообщение: до 18 лет - «Доступ ограничен»; от 18 до 65 лет - «Доступ разрешен»; старше 65 лет - «Рекомендуется упрощенный режим».

Результат выполнения работы:

Игра крестики-нолики

Задание: Разработать игру крестики-нолики для браузера, в которой можно перед началом игры выбрать размер поля. Поле не должно ограничиваться размером 3x3 (это минимальный размер поля). Критерий приемки: понятный пользовательский интерфейс, работающая логика игры.

Третья лабораторная

Приложение ToDo List (локальное хранилище)

Задание: Разработать приложение ToDo List в котором существует список дел и каждый элемент должен иметь обязательно имя (Сделать ДЗ) и опциональное описание + элемент должен быть отмечен , что он сделан или нет. Обязательно должна быть возможность добавлять и удалять элементы из списка. Элементы должны храниться и быть доступными даже после перезапуска браузера.

Однако при старте приложение должно загружать список дел с сервера с помощью Fetch API в память и затем в можете редактировать их и добавлять. При нажатии на каждую запись должна открываться отдельная страница с деталями вашей записи.
