Kotlin

Генератор репортов пользователя github

Задание: Необходимо разработать консольное приложение, позволяющее получать данные из внешнего источника, обрабатывать их и формировать отчет в формате CSV. На первом этапе требуется создать новый проект в среде разработки IntelliJ IDEA с использованием системы сборки Maven и настроить его для работы с языком Kotlin. Далее необходимо подключить библиотеку HTTP-клиент OkHttp для выполнения запросов. При необходимости допускается использование дополнительных библиотек для обработки JSON-данных (Jackson или kotlin.serialization). В качестве источника данных следует использовать GitHub REST API. Приложение должно выполнять HTTP GET-запрос для получения информации о репозиториях заданного пользователя. В ответе API необходимо извлечь следующие параметры: название репозитория, количество звезд, количество форков, используемый язык программирования и дату последнего обновления. Полученные данные должны быть преобразованы в структурированный вид с использованием классов Kotlin. На следующем этапе необходимо реализовать формирование CSV-отчета, содержащего извлеченные данные. Файл должен включать столбцы с названием репозитория, количеством звезд, числом форков, языком программирования и датой последнего обновления. Сформированный CSV-файл должен сохраняться в файловой системе и корректно открываться в табличных редакторах.

Дополнительные условия:

1. Добавить ввод имени пользователя через консоль

2. Рассчитать агрегированные показатели (среднее количество звезд)

3. Обработать ошибки (например, пользователь не найден)
